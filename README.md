# Convenience Store Simulation

An interactive simulation of the "Emotions and Firm Performance" convenience-store study (Sutton & Rafaeli, 1988): 576 artificial stores, three switchable mechanisms, the original regression run on the artificial data, and the true effect the original design could never observe.

Open it in a browser: https://bluetenhonig.github.io/convenience-store-simulation/

Linda Samsinger, University of St.Gallen. Crafting and Evaluating Research Designs, autumn 2026. Alternative research design.
